# Level Check: Existing Routines and Exercises

Reviewed against the rubric below. One row per existing routine and exercise. A level is changed only where it disagrees with the rubric. Changed rows have `needs_review` set to yes.

## Rubric

- **low**: mobility, recovery, or controlled work with no load above light. No fast or explosive movement.
- **moderate**: loaded sets or sustained bodyweight work the user can hold at a steady pace. No maximal effort.
- **high**: heavy loads, maximal effort, explosive or plyometric movement, or a skill with real injury risk. Requires a caution.
